HOW TO INSTALL & RUN ON ANY WINDOWS LAPTOP:
--------------------------------------------------------------------

METHOD 1 (Recommended - Single File All-In-One Installer):
  *** NO NEED TO COPY THOUSANDS OF LOOSE FILES! ***
  1. Simply copy ONE single file to your USB pendrive:
     * "INSTALL-PEYALA-ALL-IN-ONE.bat" (Single-file batch installer), OR
     * "Peyala-POS-AllInOne-Installer.exe" (Single-file executable installer)
  2. Plug your pendrive into ANY Windows laptop.
  3. Double-click that ONE file directly from the pendrive!
  4. What it does automatically in ~20 seconds:
     * Extracts the complete POS system into C:\Peyala (or custom folder).
     * Includes embedded MongoDB database, offline auth vault, and portable Node.js runtime.
     * Compiles native PeyalaPOS.exe with your official Peyala logo.
     * Places the "Peyala POS" shortcut directly on your Windows Desktop!
  5. It immediately launches Peyala POS ready for orders!

METHOD 2 (Developer / Source Folder Deployment):
  1. Copy the entire "peyala_v8" folder to the laptop.
  2. Double-click "INSTALL-PEYALA-POS.bat".


--------------------------------------------------------------------
DAILY LAUNCHING:
--------------------------------------------------------------------
You can start Peyala POS anytime by double-clicking:
  * "Peyala POS" shortcut on your Windows Desktop (with your logo), OR
  * "start-peyala-app.bat" (in this folder), OR
  * "PeyalaPOS.exe" (in this folder)

The POS will automatically:
  1. Check and free ports 3000 & 4000
  2. Launch the local Backend API (Port 4000)
  3. Launch the high-speed production Frontend (Port 3000)
  4. Open the dedicated native POS window with direct hardware thermal printing!

--------------------------------------------------------------------
MOBILE WAITER ORDERING OVER RESTAURANT WI-FI (LAN):
--------------------------------------------------------------------
1. Connect mobile phones or tablets to the same restaurant Wi-Fi as this laptop.
2. Find the laptop's local IP address (e.g., http://192.168.29.241:3000).
3. Waiters can open http://<laptop-ip>:3000/tables on their phone browsers, OR
4. Install the dedicated Android App ("Peyala-POS.apk"):
   - Download directly from: http://<laptop-ip>:3000/Peyala-POS.apk
   - Or copy "Peyala-POS.apk" from your pendrive directly to Android devices!
5. Orders punched at tables will automatically print KOT tickets on the
   counter thermal printer connected to this laptop!

--------------------------------------------------------------------
KEYBOARD SHORTCUTS & CONTROLS:
--------------------------------------------------------------------
* Fullscreen Kiosk Mode:   Press [F11] to toggle fullscreen/windowed
* Reload Page:             Press [F5] or [Ctrl] + [R]
* Exit Application:        Press [Alt] + [F4] or right-click System Tray icon
* Emergency Server Stop:   Double-click "stop-local-server.bat"
