HOW TO RUN ON YOUR WINDOWS LAPTOP:
--------------------------------------------------------------------

STEP 1: Copy this folder
  - Copy this entire folder from your USB pendrive onto your Windows
    laptop (for example, to C:\Peyala or your Desktop/Documents).
  - (You can also run directly from the pendrive!)

STEP 2: First-Time Setup (Run once)
  - Double-click: "setup-windows.bat"
  - What this does:
    * Checks if Node.js is installed. If not, it can automatically
      download a portable Node.js runtime for you!
    * Installs required dependencies for Windows.
    * Compiles the native "PeyalaPOS.exe" application.
    * Places a "Peyala POS Station" shortcut on your Windows Desktop!

STEP 3: Launching the POS Station
  - Simply double-click:
      * "start-local-kiosk.bat" (in this folder), OR
      * "Peyala POS Station" (on your Windows Desktop), OR
      * "PeyalaPOS.exe" (for silent background running with System Tray icon)

  - The POS will automatically:
      1. Clean and free ports 3000 & 4000
      2. Start the Backend API (Port 4000)
      3. Start the Next.js Frontend (Port 3000)
      4. Open Google Chrome or Microsoft Edge in full-screen Kiosk mode
         with silent thermal receipt auto-printing!

--------------------------------------------------------------------
KEYBOARD SHORTCUTS & CONTROLS:
--------------------------------------------------------------------
* Exit Kiosk Mode:      Press [Alt] + [F4]
* Toggle Fullscreen:    Press [F11]
* Stop Local Servers:   Double-click "stop-local-server.bat"
* Windowed App Mode:    Run "start-local-kiosk.bat --windowed"
